## Project Description
This is an Event Invitation Website created as part of Lab 12. The website invites visitors to an event at FAST NUCES Islamabad and provides information about its schedule, venue, and attendance confirmation.

## Website Theme
Event Invitation

The website uses a brown background, black headings, and Verdana font, maintaining the theme of Lab 11.

## Website Pages
1. **Home:** Introduction and event invitation.
2. **Schedule:** Event timings and activities.
3. **Venue:** FAST NUCES Islamabad campus information and pictures.
4. **RSVP:** Form to confirm attendance.
